# Inputs

Drop the five class documents here under these names (any of `.docx`, `.pdf`, `.md`, `.txt`). The graph refuses to run an exercise whose inputs are missing.

| File | What it is | Needed for |
|---|---|---|
| `deal-description.*` | Description of the Proposed Acquisition | Ex 1, 2, 4, 5 |
| `pubco-draft-nda.*` | Pubco's draft NDA (Class 8 materials) | Ex 4, 5 |
| `target-markup.*` | Target's markup of the Pubco draft | Ex 4, 5 |
| `comparison-redline.*` | The comparison/redline provided with the markup | Ex 4, 5 |
| `precedent-nda.*` | Pro-buyer precedent NDA from Westlaw or Lexis | Ex 2, 4, 5 |
| `diligence-considerations.*` | Your Starbucks/Lipton Diligence Considerations file | Ex 3, 4, 5 |

These are course materials. Before committing them to a public repository, check that your course and the Westlaw/Lexis terms allow it; otherwise keep them local (they're listed in `.gitignore`).
